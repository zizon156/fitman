# 핏맨 — 옷발 근육 재단소

제작 · 체육교사 이형호 (고양 풍동고등학교)

아이폰·갤럭시 양쪽에서 앱처럼 쓰는 웨이트 루틴 앱입니다. 설치도, 심사도, 비용도 없습니다.
링크 하나만 있으면 학생 폰에 아이콘이 생깁니다.

## 올리는 방법 (GitHub Pages · 무료)

1. github.com 가입 후 오른쪽 위 `+` → **New repository**
2. 이름을 `fitman`으로 짓고 **Public** 선택 → Create
3. 저장소 화면에서 **Add file → Upload files**
4. 이 폴더 안의 것을 **통째로** 끌어다 놓기
   (`index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더, `img` 폴더)
5. 아래 **Commit changes** 클릭
6. **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/ (root)` → Save
7. 1~2분 뒤 주소가 뜹니다 → `https://아이디.github.io/fitman/`

이 주소를 QR로 만들어 체육관에 붙이거나 학급 단톡방에 올리면 끝입니다.

## 학생 안내 문구 (그대로 복사해서 쓰세요)

> **아이폰** — 사파리로 링크를 열고 아래 공유 버튼(⬆️) → `홈 화면에 추가`
> **갤럭시** — 크롬으로 링크를 열면 아래에 설치 버튼이 뜹니다. 안 뜨면 `⋮` → `앱 설치`
>
> 설치하면 주소창 없이 전체화면으로 열리고, 지하 헬스장처럼 데이터가 안 터지는 곳에서도 그대로 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (루틴 생성·운동 모드·식단·팁) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체화면 설정 |
| `sw.js` | 오프라인 캐시. 첫 실행 때 사진 90장을 미리 받아둡니다 |
| `icons/` | 홈 화면 아이콘 |
| `img/` | 동작 사진 90장 (45종목 × 시작/끝) |

## 내용을 고쳤을 때

`index.html`을 수정해 다시 올린 뒤, `sw.js` 첫 줄의
`const V = "fitman-v1";` 을 `"fitman-v2"` 로 바꿔서 같이 올리세요.
이 숫자가 바뀌어야 학생 폰의 옛 화면이 새것으로 교체됩니다.

## 출처 및 저작권

- 동작 사진: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) — Unlicense (퍼블릭 도메인)
- 중량 기준: Strength Level, ExRx, FitnessVolt 체중 대비 기준표 종합
- 단백질 기준: ISSN 포지션 스탠드 1.4~2.0 g/kg, Morton 2018 메타분석 변곡점 1.6 g/kg
- 칼로리: Mifflin-St Jeor 공식 + 주당 훈련 일수 활동계수

앱 구성·설계·훈련 문구는 제작자의 창작물입니다. 동작 사진은 퍼블릭 도메인 자료를 재배포한 것으로
별도의 표기 의무는 없으나 출처를 앱 하단에 함께 밝혀 두었습니다.

이 앱은 운동에 관한 일반적인 정보를 제공할 뿐 의학적 진단이나 처방이 아닙니다.

## 알아두실 점

- 서비스 워커는 **https** 에서만 작동합니다. GitHub Pages는 자동으로 https라 그냥 됩니다.
  파일을 더블클릭해서 여는 방식(`file://`)으로는 오프라인 기능이 켜지지 않습니다.
- 휴식 타이머는 시계 기준이라 화면을 꺼도 시간이 밀리지 않습니다. 다만 화면이 꺼진 동안에는
  알림음이 울리지 않으니, 세트 사이에는 화면을 켜두는 편이 좋습니다.
- 저장한 몸 정보는 학생 폰 안에만 있습니다. 서버로 아무것도 보내지 않습니다.
